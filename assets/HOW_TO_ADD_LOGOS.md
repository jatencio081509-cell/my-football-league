# How to add your logos

After `git pull`, open the `assets` folder on your computer.

## 1. App logo
Replace this file with your logo image (keep the same name):
- `assets/logos/app/logo.png`

## 2. Loading intro (10 seconds)
Put **one** of these in `assets/logos/app/`:
- `loading.mp4` (best)
- `loading.webm`
- `loading.gif`
- or replace `loading.png` with a still image

## 3. Football field
Replace:
- `assets/field/field.png`

### Tip
In Finder / File Explorer: drag your real image onto the placeholder file and choose **Replace** when asked. Do not rename the file.

Then commit and push if you use GitHub, or just run the app locally:
```bash
npm start
```
