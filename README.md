# My Football League

A custom football league simulator / game logger built with **Electron**.

You use your own dice in real life, then enter the results of each play into this program.
The program tracks the score, quarters, game clock, downs, field position, and play-by-play.

## Features (planned)
- 32 teams
- Full season schedule
- Player rosters
- Individual play entry
- Live score + clock + downs tracking
- League standings

## Current Stage
Stage 1 – Basic single game with play entry (Electron desktop app)

## How to run

1. Make sure you have **Node.js** installed
2. Open a terminal in this folder
3. Install dependencies:

```bash
npm install
```

4. Start the app:

```bash
npm start
```

The app window should open.
